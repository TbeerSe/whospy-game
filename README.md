# 🕵️‍♂️ ШПИОН // CLASSIFIED FIELD GAME

Интерактивная браузерная психологическая игра по мотивам известной настольной игры «Находка для шпиона» (Spyfall). Проект разработан на чистом стеке **Vanilla JS** без использования внешних библиотек и фреймворков, оптимизирован для мобильных устройств (Mobile First) и готов к деплою на GitHub Pages.

---

## ⚡ Ключевые особенности (Текущая версия)

*   **🌀 Истинный Рандом (Entropy-based TRNG):** В отличие от стандартного `Math.random()`, распределение ролей завязано на уникальный пул аппаратного хаоса. В момент запуска миссии система собирает физические показатели устройства: микросекунды клика (`performance.now()`), уровень заряда батареи, объем занятой оперативной памяти браузера и координаты нажатия на экран. Данные хэшируются алгоритмом для создания непредсказуемого сида.
*   **🚨 Режим «Паранойя»:** Уникальный игровой пресет, при котором шпионами становятся абсолютно все участники. Каждый игрок думает, что он единственный шпион в комнате, что порождает максимальный уровень недоверия и психологического напряжения.
*   **👥 Режим «Сообщник» (Лже-шпион):** Секретный протокол, добавляющий в игру сообщника. Он знает локацию и помогает шпиону путать следствие, но сам шпион не знает, кто его союзник.
*   **🛠 Кастомные паки:** Помимо встроенных локаций (Орбитальная станция, Подводная лодка и др.), игроки могут создавать свои собственные паки мест и ролей, которые автоматически сохраняются в `localStorage` устройства.
*   **🎬 Поочередное раскрытие карт:** Проработанный финал игры — после истечения таймера или принудительной остановки, досье агентов плавно «въезжают» на экран по очереди с задержкой в 0.5 секунды, сохраняя интригу до самого конца.

## 🚀 Архитектура проекта

Проект полностью автономен и состоит из трех базовых файлов:
1.  `index.html` — Семантическая структура интерфейса и экранов операций.
2.  `app.js` — Модульная логика игры, система таймеров, менеджер состояний и TRNG-генератор.
3.  `style.css` — Футуристичный темный кибер-интерфейс с эффектами матового стекла (`backdrop-filter`), неонового свечения и плавными анимациями переходов.

## 🕹 Как играть

1.  **Подготовка:** Введите имена участников (минимум 3 игрока).
2.  **Настройка:** Выберите время раунда, режим распределения (Классический или Сообщник) и количество шпионов (или режим «Паранойя»).
3.  **Выбор локации:** Отметьте локацию, в рамках которой будет проходить текущая операция.
4.  **Считывание хаоса:** Нажмите «Начать операцию». Система запустит 2-секундный анимированный аудит энтропии вашего устройства и сгенерирует роли.
5.  **Раздача:** Передавайте телефон по кругу. Каждый игрок нажимает «Показать роль», запоминает свою карточку и скрывает ее.
6.  **Допрос:** Запустите таймер. Задавайте друг другу вопросы. Задача мирных — вычислить шпиона. Задача шпиона — понять, где он находится, не выдав себя.
