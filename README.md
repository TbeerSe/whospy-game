# 🕵️♂️ ШПИОН // CLASSIFIED FIELD GAME

**(Patch 0.5.2)**

Интерактивная браузерная игра по мотивам настольной игры «Находка для шпиона». Разработана на чистом **Vanilla JS** без внешних библиотек и сборщиков. Оптимизирована под мобильные устройства.

Текущая версия включает: экономику и ранги, магазин гаджетов, интерактивное судейство, процедурный звук через Web Audio API, **мультивыбор локаций**, **гибкую настройку количества шпионов через вероятности** и **кастомные паки локаций**.

## ⚡ Ключевые особенности

1. **TRNG на энтропии:** генерация ролей и выбора локации на основе аппаратных показателей (клики, память, батарея, язык системы).
2. **Экономика и ранги:** баланс коинов влияет на статус игрока (Должник Синдиката, Агент под прикрытием, Элита МИ-6) со своими бонусами и штрафами.
3. **Маркет снаряжения:** покупка гаджетов (радары, глушитель, детектор лжи, страховка). Если роль не подошла — предмет замораживается до следующей игры.
4. **Случайные события:** экономический кризис, охота за головами, анонимный благотворитель — с шансом 15% при старте.
5. **Интерактивное судейство:** модули голосования, перехвата локации и детектора лжи встроены в экран игры.
6. **Процедурный звук:** генерация эффектов через Web Audio API, без аудиофайлов.
7. **Гибкие режимы:** «Паранойя» (до 100% шпионов), «Сообщник», фиксированное или случайное количество шпионов.
8. **Пул локаций:** выбор нескольких локаций перед игрой — игра случайно выберет одну из них.
9. **Кастомные паки:** создание собственных локаций и ролей.
