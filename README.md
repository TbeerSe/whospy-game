# ШПИОН — браузерная игра по мотивам Spyfall

Чистый HTML/CSS/JS (ES-модули), без сборки. Данные хранятся в `localStorage`.

## Запуск

ES-модули не работают с `file://`, нужен любой статический сервер:

```
python3 -m http.server 8765
# открыть http://localhost:8765/
```

На GitHub Pages работает как есть.

Игру можно установить на экран «Домой» (PWA): после первого запуска по
http(s) она открывается и без интернета. Пока интернет есть, всегда
загружаются свежие файлы; при выходе новой версии поменяйте
`CACHE_NAME` в `sw.js`.

## Правила кратко

- 4+ игрока, 5+ локаций. Мирные знают локацию, шпионы — нет.
- На карте роли каждому выдаётся **личный 4-значный код**. По нему шпион
  открывает перехват локации, а любой игрок — Верификатор. Ошибки кода
  одинаковы для всех причин, после 5 ошибок — блокировка на 15 с.
- Победа мирных: все шпионы выгнаны голосованием или провалили перехват.
- Победа шпионов: таймер истёк / перехват удался / мирных не больше шпионов.
- На выбор и подтверждение локации при перехвате даётся **15 секунд**.
  Истечение этого времени или общего таймера в открытом окне перехвата
  засчитывается как провал: шпион выбывает, попытка расходуется.
- После каждой завершённой роли шпиона вес игрока при следующем выборе
  снижается на 25 процентных пунктов (100% → 75% → 50% → минимум 10%).
  Завершённый раунд в роли мирного сбрасывает серию; отмена раунда её не меняет.
- «Отменить раунд» ничего не начисляет и возвращает предметы.
- Если страница перезагрузилась посреди раунда — игра предложит продолжить
  (таймер на паузе) или отменить раунд.

## Экономика (все константы — `src/core/state.js`)

Игра с нулевой суммой: проигравшие платят **банк раунда**, победители делят.

| Константа | Значение | Смысл |
|---|---|---|
| `POT_PER_CIVILIAN` / `MAX_POT` | 30 / 240 | банк = 30 × мирных, не больше 240 |
| `PARTICIPATION_BONUS` | 15 | всем за сыгранный раунд (единственный источник новых монет) |
| `INITIATOR_WEIGHT` | 2 | доля инициатора победного голосования |
| `PARTIAL_INITIATOR_BONUS` | 0.5 | за каждого шпиона, пойманного раньше финала |
| `INTERCEPTOR_WEIGHT` | 2 | доля шпиона, угадавшего локацию |
| `EXPELLED_WIN/LOSS_WEIGHT` | 0.5 / 1.5 | выгнанный шпион в команде победителей / проигравших |
| `WRONG_VOTE_STEP` | 0.15 | −15% к доле выигрыша, +15% к доле проигрыша за неверный голос |
| `INTERCEPT_POT_PER_LOCATION` | 0.25 (×0.5…×2) | множитель банка при удачном перехвате растёт с размером пула |
| `DEBTOR_TAX` | 0.25 | с отрицательным балансом — 25% выигрыша уходит в долг, покупки недоступны |
| `ELITE_THRESHOLD` / `ELITE_DISCOUNT` | 500 / 0.1 | скидка на покупки |
| `CRISIS_CHANCE` / `HUNT_STEAL` | 0.15 / 50 | случайные события |
| `TIMER_NOISE_STEPS` | `[-60,-30,0,30,60]` | скрытая добавка к таймеру (чтобы время не выдавало Глушитель/Допрос); `[0]` — выключить |
| `SPY_REPEAT_WEIGHT_STEP` / `SPY_REPEAT_MIN_WEIGHT` | 0.25 / 0.1 | снижение веса за серию ролей шпиона и его нижняя граница |
| `INTERCEPT_WINDOW_SECONDS` | 15 | лимит выбора локации в окне перехвата |

Цены предметов — `src/constants/gadgets.js`.

## Структура

```
index.html
css/            tokens → reset → base → layout → components → features/*
src/core/       state (константы и состояние), dom, storage, audio, utils
src/features/   economy, rounds, judging, intercept, verificator, accessCode,
                roundStore (снимок раунда), resume, timer, dealing, gadgets, ...
src/constants/  locations (24 локации), gadgets
tests/          e2e.cjs, unit.cjs, mechanics.cjs, shots.cjs (Playwright)
```

Циклические импорты разорваны колбэками (`setOnInterceptFinished`,
`setOnTimerExpired`, `setOnVerificatorUsed`) — регистрируются в `main.js`.

## Тесты

```
npm install && npx playwright install chromium
npm run serve          # статический сервер на :8765 (в отдельном терминале)
npm test               # economy + smoke + unit + mechanics + e2e
npm run test:unit      # нулевая сумма, EV ролей, радар, шум таймера, распределения
npm run test:mechanics # ротация шпионов, оба лимита перехвата, мобильная раскладка
npm run test:e2e       # 11 сценариев через реальный UI (~3 мин)
node tests/shots.cjs   # скриншоты на телефоне
```

Playwright берётся из `node_modules`; если он стоит в другом месте, укажите
путь в переменной `PLAYWRIGHT_PATH`. Тесты также запускаются на GitHub
Actions (`.github/workflows/test.yml`).

## Случайность и безопасность

- **Кто шпион и какая локация** выбирается напрямую из
  `crypto.getRandomValues` (`createCryptoRandom` в `src/core/utils.js`),
  а не из 32-битного сида. Личные коды — тоже из crypto.
- Сид раунда (`state.entropySeed`) питает только воспроизводимые потоки:
  радар, вердикты Верификатора, шум таймера. Их нельзя «перебросить»
  перезагрузкой страницы или отменой раунда. Экран «аудита энтропии» —
  оформление; реальную непредсказуемость даёт crypto.
- Лимит попыток ввода кода (5 ошибок → 15 с) сохраняется в снимке раунда
  и не сбрасывается обновлением страницы.
- Игра рассчитана на **одно устройство по кругу**. Снимок раунда в
  `localStorage` (`spyfall_active_round`) содержит роли и коды открытым
  текстом, поэтому тот, кто держит телефон, может увидеть их через
  DevTools. От этого честно защититься нельзя, это ограничение формата.

## Что нового в 0.9.2

- Голосование сбрасывается, если подозреваемый или инициатор выбыл
  (например, провалил перехват); `submitVote` не засчитывает поимку
  выбывшего, а выбывшие голосующие не учитываются в кворуме.
- Закрытие окна перехвата любым способом (системная «Назад», жест)
  считается провалом, а не бесплатной отменой.
- Раздача на телефоне: при показе роли карточка получателя прячется,
  роль и код помещаются на экран 360×640, кнопка «Скрыть» закреплена внизу.
- Шрифты не мельче 12px (кроме декоративного штампа), `100dvh` вместо
  `100vh`, верхний и нижний отступы учитывают `safe-area`.
- Фальшивое удостоверение: после срабатывания окно перехвата открывается
  само (без ввода кода) на 10 секунд, общий таймер стоит. Угадал —
  победа шпионов, ошибся или не успел — выбывает. Обычный перехват
  (15 секунд) тоже ставит общий таймер на паузу.
- Удалён мёртвый код: режим «ПАРАНОЙЯ», исход `spy-location-failure`
  (остался только как подпись для старой истории), `balancesBeforeRound`.
- README приведён в соответствие с кодом (5 ошибок → 15 с), опечатка
  «выберете» исправлена, добавлен `tests/fixes.cjs`.

## Что нового в 0.9.0

- Обновлены визуальный стиль, карточки, диалоги и мобильная навигация.
- Повторное выпадение шпиона остаётся возможным, но его вес снижается

## Что нового в 0.8.5

- Нулевая сумма: победители делят только реально собранное. Страховка
  и нижняя граница баланса (−500) больше не создают монеты, налог
  должника явно считается стоком (`burned`).
- Неверное голосование выгоняет только подозреваемого; инициатор и
  проголосовавшие получают штраф к доле. Есть кнопка «Отменить
  голосование», голосование больше не блокирует перехват.
- Блокировка кода: 5 попыток, 15 с.
- Кэп на суммарную добавку таймера от гаджетов: ±120 с.
- Единая `getActiveCounts()` для победы по истощению.
- Удалены режимы шпионов 1–75% и 1–100%.
- Тесты экономики без браузера: `npm run test:economy`.

## Что нового в 0.8.4

## Ключи localStorage

Прежние ключи сохранены, добавлены `spyfall_active_round` (снимок раунда)
и `spyfall_spy_streaks` (серии завершённых ролей шпиона).
