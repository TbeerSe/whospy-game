# 🕵️‍♂️ ШПИОН // CLASSIFIED FIELD GAME (Patch 0.3.2)

Интерактивная браузерная игра по мотивам настольной игры «Находка для шпиона». Разработана на чистом **Vanilla JS** без внешних библиотек, оптимизирована под мобильные устройства и готова к деплою на GitHub Pages. Версия **Patch 0.3.2** включает экономику, систему рангов, магазин гаджетов, интерактивное судейство и процедурный звук [source: 1].

---

## ⚡ Ключевые особенности
1. **TRNG на энтропии:** Генерация ролей на основе аппаратных показателей (клики, память, батарея).
2. **Экономика и ранги:** Баланс коинов влияет на статус игрока (должник, агент, элита МИ-6) со своими бонусами и штрафами [source: 1].
3. **Маркет снаряжения:** Покупка гаджетов (радары, глушители, детектор лжи), которые замораживаются до выпадения нужной роли [source: 1].
4. **Случайные события:** Глобальные кризисы и охота за головами с шансом 15% при старте [source: 1].
5. **Интерактивное судейство:** Панели голосования, перехвата локации и детектора лжи [source: 1].
6. **Процедурный звук:** Генерация звуков через Web Audio API без тяжелых аудиофайлов [source: 1].
7. **Режимы:** «Паранойя» и «Сообщник» [source: 1].

## 🚀 Архитектура и запуск
Проект состоит из `index.html`, `app.js` и `style.css`. Подробную инструкцию по игровому процессу и полные исходные коды можно найти в репозитории [GitHub - TbeerSe/whospy-game](https://github.com/TbeerSe/whospy-game/tree/main) [0.1.4, source: 1].
