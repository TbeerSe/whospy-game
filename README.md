# 🕵️♂️ ШПИОН // CLASSIFIED FIELD GAME

**(Patch 0.4.1)**

Интерактивная браузерная игра по мотивам настольной игры «Находка для шпиона». Разработана на чистом **Vanilla JS** без внешних библиотек, оптимизирована под мобильные устройства и готова к деплою на GitHub Pages.

Версия **Patch 0.4.1** включает экономику, систему рангов, магазин гаджетов, интерактивное судейство, процедурный звук, а также **мультивыбор локаций** и **гибкую настройку количества шпионов через вероятности**.

## ⚡ Ключевые особенности

1. **TRNG на энтропии:** Генерация ролей и выбора локации на основе аппаратных показателей (клики, память, батарея, язык системы).
2. **Экономика и ранги:** Баланс коинов влияет на статус игрока (должник, агент, элита МИ-6) со своими бонусами и штрафами.
3. **Маркет снаряжения:** Покупка гаджетов (радары, глушители, детектор лжи, страховка), которые замораживаются до выпадения подходящей роли.
4. **Случайные события:** Глобальные кризисы, охота за головами и анонимный благотворитель с шансом 15% при старте.
5. **Интерактивное судейство:** Панели голосования, перехвата локации и детектора лжи встроены прямо в экран игры.
6. **Процедурный звук:** Генерация звуков через Web Audio API без тяжелых аудиофайлов.
7. **Гибкие режимы:** «Паранойя» (до 100% шпионов), «Сообщник», фиксированное или случайное количество шпионов.
8. **Пул локаций:** Выбор нескольких локаций перед игрой — игра случайно выберет одну из них.
9. **Кастомные паки:** Возможность создавать собственные локации и роли.

## 🚀 Архитектура и запуск

Проект состоит из трех файлов:
- `index.html` — разметка интерфейса.
- `app.js` — вся игровая логика, TRNG, экономика, судейство.
- `style.css` — адаптивные стили с поддержкой темной темы.

**Запуск локально:** просто откройте `index.html` в браузере. Никаких сборщиков и зависимостей не требуется.

**Деплой:** проект готов к публикации на GitHub Pages (Settings → Pages → Deploy from branch → main).
